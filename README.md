### 🔭 Selected work

- **[Hospital Operations Intelligence Suite](https://github.com/Surbhit1508/Hospital-Ops-Suite)**: one pipeline on real public data covering forecasting, readmission classification, length-of-stay regression, clinical-note NLP and bed-allocation optimization. Gradient boosting beats logistic regression on readmission (**ROC-AUC 0.685 vs 0.669, p<0.0001**). It also caught an upstream NLP class-imbalance bug that was producing a fake capacity shortage downstream.
- **[RAGBench](https://github.com/Surbhit1508/RAG-Bench)**: compares 9 RAG configurations, each changing one design choice, on a 150-question benchmark with paired bootstrap tests. Top-5 retrieval keeps hit rate but **significantly lowers answer F1 (p<0.0001)**. Runs 100% locally on CPU.
- **[Exam Score Predictor](https://github.com/Surbhit1508/exam-score-predictor)**: Streamlit app with gradient boosting (**holdout R² 0.888**), conformal 80% intervals that hit **80% empirical coverage**, exact Shapley values written from scratch, and a lowest-effort study-plan optimizer. Covered by CI.
